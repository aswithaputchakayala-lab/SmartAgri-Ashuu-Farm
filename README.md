# 🌱 SmartAgri – Smart Agriculture AI Agent

**SmartAgri** is an intelligent agriculture assistant designed to help farmers monitor crop conditions, identify potential risks, and receive suitable recommendations based on their field observations.

## 🎯 Project Objective
To support farmers in making better crop-management decisions using AI concepts and rule-based reasoning.

## ✨ Key Features
- **Crop Analysis:** Enter crop details, soil moisture, weather, growth stage, and visible symptoms.
- **Risk Identification:** Identify possible crop-related risks based on entered information.
- **Smart Recommendations:** Display suitable actions and suggestions.
- **Dashboard:** View crop analysis statistics and summaries.
- **Analysis History:** Access previously saved crop analysis records.
- **Farmer Profile:** Manage farmer information and crop details.
